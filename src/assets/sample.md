# 简墨

一个 **现代**、简洁、清新的 Markdown 编辑器。所见即所得，同时保留纯 Markdown 的输入手感。

## 为什么好写

直接在正文里敲 Markdown 语法即可自动转换，不用来回点工具栏：

- 输入 `# ` 得到一级标题，`## ` 二级，以此类推
- 输入 `- ` 或 `1. ` 得到列表，`[ ] ` 得到待办
- 输入 `> ` 得到引用，`---` 回车得到分割线
- 用一对反引号包住文字得到行内代码，例如 `const a = 1`
- 输入 `**粗体**`、`*斜体*`、`~~删除线~~` 会自动变成对应样式

## 表格

| 能力 | 快捷键 | 说明 |
| --- | --- | --- |
| 加粗 | Ctrl/⌘ + B | 也支持 `**text**` 输入规则 |
| 标题 | Ctrl/⌘ + Alt + 1~4 | 也可以用 `#` 前缀 |
| 保存 | Ctrl/⌘ + S | 自动存到本地，随时导出 .md |

> 提示：右上角可以切换主题、专注模式与打字机模式。按 `Ctrl/⌘ + /` 查看全部快捷键。
